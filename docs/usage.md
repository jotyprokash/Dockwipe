# Usage

### Common

```bash
dockwipe --analyze
dockwipe --status
dockwipe --smart
```

### Dry run

```bash
dockwipe --dry-run --full
dockwipe --dry-run --containers
```

### Targeted cleanup

```bash
dockwipe --containers
dockwipe --images
dockwipe --volumes
dockwipe --networks
dockwipe --cache
```

### Factory reset (destructive)

```bash
dockwipe --full
```
